# Jigsaw Puzzle

เกมต่อภาพรถที่เลือกระดับความยากได้ 4 ระดับ สร้างด้วย HTML, CSS และ JavaScript แบบไม่ใช้ไลบรารีเพิ่มเติม

## วิธีเล่น

1. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์บนเครื่อง PC
2. เลือกระดับที่ต้องการ: **ง่าย 20 ชิ้น**, **ปานกลาง 25 ชิ้น**, **ยาก 30 ชิ้น** หรือ **ยากมาก 45 ชิ้น**
3. ลากชิ้นส่วนจากพื้นที่ **ชิ้นส่วน** ไปยังตำแหน่งที่ถูกต้องบนกระดาน ชิ้นส่วนที่วางใกล้เป้าหมายจะดูดเข้าที่โดยอัตโนมัติ
4. เมื่อต่อครบจะแสดงข้อความว่ายอดเยี่ยมและต่อจิ๊กซอว์หมดแล้ว
5. กด **เริ่มใหม่** เพื่อสุ่มเล่นระดับเดิม หรือกด **เลือกระดับใหม่** เพื่อกลับไปเลือกระดับอื่น

## เสียง

- เพลงพื้นหลังใช้ไฟล์ `background-music.mp3` ซึ่งจะเริ่มเล่นเมื่อเลือกระดับเกมและเล่นซ้ำเมื่อเพลงจบ
- กดปุ่ม **ปิดเพลง / เปิดเพลง** เพื่อควบคุมเพลงระหว่างเล่น
- มีเสียงเอฟเฟกต์เมื่อหยิบและวางชิ้นจิ๊กซอว์ โดยสร้างเสียงจากเบราว์เซอร์

ต้องเก็บไฟล์ `car.jpg` ไว้ในโฟลเดอร์เดียวกับ `index.html`
